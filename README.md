This is an interective prototype of CareerOS along with its Challenge Modules for Talentbank Tech Hackathon from the first cohort Team PeckingDucks.

You may access the Live Demo through this link: https://talentbank-career-os-1.vercel.app/

## Product Architecture
Framework: NextJS

Frontend: React & Tailwind CSS

Backend: Express

Database: Turso

## Project Disclaimer
This prototype project uses Gemini AI to process and assist user on various platform feature, all outputs are for demonstration purpose only.
